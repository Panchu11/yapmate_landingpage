# YapMate Landing Page

Official landing page for YapMate - AI-Powered Twitter Reply Generator for Crypto Twitter.

## 🚀 Features

- Modern, responsive design built with React and Tailwind CSS
- TypeScript for type safety
- Vite for fast development and building
- Optimized for Vercel deployment
- SEO-friendly with meta tags
- Accessibility compliant (WCAG)

## 🛠️ Tech Stack

- **Frontend Framework:** React 18
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **Deployment:** Vercel
- **Icons:** React Icons
- **Animations:** Framer Motion

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/Panchu11/yapmatelandingpage.git

# Navigate to the project directory
cd yapmatelandingpage

# Install dependencies
npm install

# Start the development server
npm run dev
```

## 🏗️ Project Structure

```
/yapmatelandingpage
├── public/          # Static assets
├── src/
│   ├── components/  # React components
│   ├── pages/       # Page components
│   ├── App.tsx      # Main app component
│   ├── main.tsx     # Entry point
│   └── index.css    # Global styles
├── index.html       # HTML template
├── tailwind.config.js
├── postcss.config.js
├── vite.config.ts
└── vercel.json      # Vercel configuration
```

## 🚀 Deployment

The project is configured for easy deployment to Vercel:

```bash
# Build the project
npm run build

# Deploy to Vercel
vercel
```
